steps:
  - "State the harmful state change and timestamp."
  - "Ask whether temporary restoration is technically possible pending review."
  - "If yes, request immediate provisional rollback with expiry and owner."
  - "If no, request written explanation of missing rollback capability and mitigation plan."
failureLooksLike:
  - "Only apology language is offered while harmful state persists."
  - "No owner can explain why rollback capability does not exist."
legitimateDemand:
  - "A provisional restoration path that limits irreversible harm during disputes."

Systems that can only move in one direction convert ordinary error into severe injury.
