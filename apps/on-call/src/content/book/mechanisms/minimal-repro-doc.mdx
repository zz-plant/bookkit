## Scope

Keep repro discipline about the written, minimal, handoff-ready reproduction. Diagnosis depth lives in diagnostics.

## Boundaries

- A repro is a claim to be tested, not a verdict.
- If a fix cannot falsify the repro, the fix is unverified.
